# Predina Engenharia

Estrutura inicial do portfólio digital da Predina Engenharia.

O desenvolvimento da interface começa após a chegada das referências visuais e do PDF do portfólio. Até lá, não adicionar dados biográficos, serviços, projetos ou contatos que não tenham sido fornecidos pelo engenheiro.

## Estrutura

- `assets/`: imagens e outros arquivos estáticos.
- `assets/images/`: imagens do projeto.
- `css/`: folhas de estilo.
- `js/`: JavaScript do site.
